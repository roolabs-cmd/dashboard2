Privacy Policy

Last updated: October 30, 2026

Wall Dashboard is a personal dashboard built and used by one person to show weather, calendar events, and tasks on a home display.

What the app accesses

With the owner's permission, the app accesses Google Calendar data (calendar names, events, and event details) so it can display events and let the owner add, edit, and delete them.

How the data is used

Calendar data is used only to show and manage the owner's own events inside the dashboard. It is not used for advertising, analytics, or any other purpose, and it is not sold or shared with anyone.

What is stored

The app stores a Google sign-in token (a refresh token) and the owner's calendar display preferences in a private database. Calendar events are loaded when needed and are not kept in a separate database.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. The stored token can also be deleted from the database.
